# CGDashboard

A PySide6-based desktop dashboard for launching and monitoring CommonGround tools.  
Includes heartbeat-driven UI buttons, process lifecycle management, and VR/Avatar pipeline integration.


## Features

- Launch and monitor external processes
- Heartbeat-driven UI feedback
- Safe process management
- Modular button system
- Clean separation of UI and backend logic


## Installation

### 1. Create a virtual environment: 
```bash
python -m venv venv
```
### 2. Activate it:

Windows: 
```bash
venv\Scripts\activate
```
macOS/Linux: 
```bash
source venv/bin/activate
```
### 3. Install dependencies: 
```python
pip install -r requirements.txt
```
### 4. Running the Dashboard
```python
python main.py
```
